QUICK START (5 MINUTES)
================================================================================

1. EXTRACT THE ARCHIVE
   tar -xzf ecommerce-platform-v1.0.tar.gz
   cd v0-project

2. CONFIGURE ENVIRONMENT
   cp .env.example .env
   
   Then edit .env and add your keys:
   - RAZORPAY_KEY_ID & RAZORPAY_KEY_SECRET
   - AZURE_STORAGE_CONNECTION_STRING
   - JWT_SECRET (generate: openssl rand -base64 32)
   - DB_PASSWORD (generate: openssl rand -base64 32)

3. START EVERYTHING WITH ONE COMMAND
   docker-compose up -d

4. ACCESS THE SERVICES
   Frontend:   http://localhost:3000
   Backend:    http://localhost:5000
   Database:   localhost:5432
   Redis:      localhost:6379

5. CREATE ADMIN ACCOUNT
   curl -X POST http://localhost:5000/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "email": "admin@example.com",
       "password": "Admin@123456",
       "first_name": "Admin",
       "last_name": "User"
     }'

   Then update user to admin in database:
   docker-compose exec postgres psql -U postgres -d ecommerce \
     -c "UPDATE users SET is_admin = true WHERE email = 'admin@example.com';"

DONE! Your e-commerce platform is running.

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Port Already in Use:
  lsof -i :5000  (find process)
  kill -9 <PID>  (kill process)
  Or change PORT in .env

Database Connection Failed:
  docker-compose down -v
  docker-compose up -d
  (This recreates fresh databases)

Cannot Connect to Redis:
  docker-compose exec redis redis-cli ping
  Should respond with: PONG

Build Fails:
  docker system prune -a
  docker-compose up --build

API Not Responding:
  docker-compose logs backend
  (Check logs for errors)

See INSTALLATION.md for more troubleshooting guides.
